# About Me

I started my journey learning pure Java, experimenting and building small projects until I felt confident with the language. At first, I thought that was enough, but a friend once told me: *"Pure Java alone won’t take you far."*  

That advice pushed me to dive into **Spring Boot**, where I faced the challenge of package architecture and annotations — obstacles that almost made a beginner programmer "bug out."  

From there, I explored databases and began testing APIs with **Postman**. Each step was intense, but the journey never really ends, because programming evolves every day with new technologies.  

Today, I work with **React + JavaScript and TypeScript**, stacks that gave me the practicality I was looking for to build applications such as **SaaS** and **E-commerce**. The ability to integrate logic with the visual interface has been a game-changer.  

I’m currently deepening my knowledge in **SOLID principles** and always striving for **Clean Code**, aiming to advance with quality and scalability in every project.
